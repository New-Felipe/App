# Organizador de Tarefas — MIT App Inventor

Aplicativo desenvolvido com o **MIT App Inventor**, com o objetivo de auxiliar na organização e no acompanhamento de tarefas pessoais.

## 📌 Sobre o projeto

Este projeto foi desenvolvido como parte de uma atividade acadêmica, cuja proposta era criar um aplicativo utilizando os recursos e as ferramentas disponibilizados pelo MIT App Inventor.

A solução escolhida foi um organizador de tarefas, pensado para facilitar o registro de atividades e o acompanhamento de sua conclusão.

O projeto foi concluído e aprovado na avaliação acadêmica.

## ⚙️ Funcionalidades

- **Criação de tarefas:** permite cadastrar novas atividades.
- **Conclusão de tarefas:** permite registrar tarefas como concluídas.
- **Gerenciamento de atividades:** possibilita organizar e acompanhar tarefas por meio do aplicativo.

## 🛠️ Tecnologia utilizada

- **MIT App Inventor** — plataforma de desenvolvimento visual de aplicativos, baseada em programação por blocos.

## 🎯 Objetivo

Aplicar conceitos de lógica de programação e desenvolvimento de aplicativos por meio de uma solução prática voltada à organização de atividades do dia a dia.

## 📚 Contexto acadêmico

O aplicativo foi desenvolvido seguindo a proposta de utilizar exclusivamente as ferramentas e os recursos disponibilizados pela plataforma MIT App Inventor.

A atividade proporcionou uma experiência prática com desenvolvimento visual, organização de funcionalidades e construção de uma aplicação funcional.
