Este é foi um trabalho feito por mim, onde criei um aplicativo com ideia central em organização de tarefas e conclusão delas. Feito no site MIT app inventor, foi requisitado pelo professor para que se usasse apenas as ferramentas do site e suas dependências.
O aplicativo foi feito com funções de criação de novas tarefas e de conclusão ilimitada para ambas as funções,
o resultado do mesmo foi um sucesso e o organizador aprovou o projeto.
